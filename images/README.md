# Nova Asian Bistro — Photo Brief

Drop photos in this folder using the **exact filenames below**. The site loads
local images first, and gracefully falls back to a temporary stock photo if a
file is missing — so you can add them one at a time without breaking the site.

## Where to source them

In order of preference:

1. **The owner's phone / camera roll** — Chef Peter and staff almost certainly
   have hundreds of photos already.
2. **Nova's Instagram / Facebook page** — re-download originals you posted.
3. **Past marketing assets** — menus, flyers, food-shoot files from prior work.
4. **A 1-hour phone shoot** — natural light through the front windows, a few
   signature dishes plated, a wide of the dining room, a tight on the sushi bar.

⚠️ **Do not download photos from Yelp, Google, or TripAdvisor reviews** —
those belong to the reviewers, and using them commercially is a copyright issue.

## File requirements

- **Format:** `.jpg` (or rename `.jpeg` → `.jpg`)
- **Color space:** sRGB
- **Optimization:** Run through [squoosh.app](https://squoosh.app) at ~80% quality
  before uploading. Target file size in the column below.

## Bonus (optional)

- `favicon.png` — 512×512, Nova's circular wordmark logo on a dark background.
- `og.jpg` — 1200×630, a single hero-quality image for social sharing previews
  (Facebook/iMessage link cards). Add `<meta property="og:image" content="images/og.jpg">` to `<head>` once added.

## Tips for a quick phone shoot

- Shoot near a window between 11am–2pm, no overhead lights.
- Wipe the lens.
- Use **portrait mode** for plates, **regular mode** for wide room shots.
- Get low and shoot at 3/4 angle for plated dishes; shoot overhead for spreads.
- Take 5+ of each — pick the best later.
